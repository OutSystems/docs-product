# Self-managed infrastructure

<div class="warning" markdown="1">

This pattern has been deprecated. If your Conversion Assessment Tool still shows this pattern, [download and update your Conversion Assessment Tool](../setup-assessement-tool.md) to the latest version.

</div>

App conversion now supports self-managed and hybrid infrastructures. You don't need to take any action for this pattern.
